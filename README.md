# Спецпартс49

Многостраничный статический сайт торгового предприятия в Магадане. Специализация — запасные части, комплектующие и расходные материалы для горнодобывающей и дорожно-строительной спецтехники Caterpillar и Komatsu: бульдозеров, погрузчиков, карьерных самосвалов и грейдеров. HTML, CSS и JavaScript, без серверной части и сторонних зависимостей для сборки.

## Структура

- `src/` — исходники одиннадцати страниц и используемые изображения.
- `src/assets/app.js` — поиск, фильтры, примеры каталога, список запроса и скачивание документа.
- `src/assets/style.css` — оформление и адаптивная вёрстка.
- `scripts/build.mjs` — подготовка демоверсии или боевого сайта.
- `scripts/check.mjs` — проверка ресурсов и правил индексации.
- `main` — исходники; `gh-pages` — готовая демонстрация.

## Локальный запуск

Из корня проекта:

```sh
python3 -m http.server 8000 --directory src
```

Открыть `http://localhost:8000`. Запуск через HTTP необходим для нормальной работы браузерного хранилища и скачивания запросов.

## Демо и индексация

Требуется Node.js 20 или новее. Установка пакетов не нужна.

```sh
npm run build:demo
npm run check:demo
```

Результат создаётся в `.demo/`, которая исключена из `main`. В каждой HTML-странице добавляется `noindex, nofollow, noarchive, nosnippet`; `robots.txt` содержит `Disallow: /`. Демо публикуется из корня ветки `gh-pages` через GitHub Pages.

У GitHub Pages проекта `robots.txt` находится внутри `/specparts49/`, поэтому основное средство закрытия индексации — метатег `noindex` на всех страницах. Это ограничение для поисковых роботов, а не контроль доступа к сайту.

## Будущий боевой сайт

```sh
npm run build:production
npm run check:production
```

Каталог `dist/` содержит боевую статическую сборку: `index, follow` на страницах и `Allow: /` в `robots.txt`. Размещать её следует на будущем рабочем домене. Ветка `gh-pages` остаётся закрытой от индексации и не используется как боевой сайт.

После выбора рабочего домена нужно добавить корректные canonical-адреса и sitemap. Источники в `main` не содержат запрета индексации.

## Обновления

Правки вносятся в `src/` и коммитятся в `main`. После проверки демосборки обновляйте обычными Git-коммитами только изменившиеся файлы в `gh-pages`, не переписывая историю ветки. ZIP/TAR-архивы и локальные сборки в `main` не добавляются.

## Доступные функции и ограничения

Работают поиск, фильтры, сортировка, карточки деталей, сохранение списка и технического черновика на устройстве, изменение количества, скачивание и копирование запроса.

- Каталог содержит 21 пример в девяти группах; реальные ассортимент, цены, совместимость и остатки не подключены.
- Контакты компании пока не заполнены.
- Запрос не отправляется менеджеру: он скачивается или копируется на устройстве.
- Онлайн-оплаты, учётных записей, CRM и серверного хранения заявок нет.
- Эти ограничения действовали и в исходном проекте; перенос на GitHub Pages дополнительных функций не отключает.

Данные компании и источник фотографии перечислены в `src/sources.html`. Логотип предоставлен заказчиком.

## Новые разделы и обращения

Главная использует структуру сайта партнёра findom.net как ориентир: поставки, поиск, каталог, производители, преимущества и обращение. Добавлены страницы manufacturers.html, offers.html и privacy.html.

Логотипы и фотографии Euroricambi/MCP предоставлены заказчиком. Сертификат Euroricambi 2025 выдан TECHNO-2K LLC, поэтому не опубликован как сертификат Спецпартс49.

Настройки почты: src/assets/contact-config.js. Пока email и endpoint пусты: форма сохраняет обращение файлом и не отправляет его. Укажите email для подготовки письма в почтовом клиенте либо HTTPS endpoint, принимающий JSON и возвращающий { success: true }. SMTP-пароли и API-токены в клиентских файлах запрещены. Настройка серверной отправки и обновление информации о данных выполняются отдельно после выбора канала.

Имя, email, телефон и согласие не сохраняются автоматически в localStorage. В нём остаётся только технический черновик и список запчастей.

Акционные позиции добавляются в SP49_OFFERS только по подтверждённым данным: title, article, manufacturer, image, price, oldPrice. Сейчас список пуст, скидки не выдуманы.
