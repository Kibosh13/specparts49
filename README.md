# Спецпартс49

Многостраничный сайт компании и самописная панель управления на PHP. Рабочий сайт размещён на Rokmere: https://specparts49.ru/. Исходники хранятся в `main`, статическая демонстрация — в `gh-pages`.

## Панель управления

Адрес: `/admin/`. Есть визуальное редактирование текста, изображений и разделов страниц, общий подвал и шапка, меню, SEO и новые страницы. Каталог управляется отдельно: товары, артикулы, применяемость, бренды, цены, остатки и импорт/экспорт CSV. Для реальных опубликованных товаров создаются отдельные HTML-страницы с canonical и записями в sitemap. Начальные 21 позиции помечены как примеры, реальные цены и остатки не выдуманы.

Панель также управляет группами товаров, 26 брендами и их логотипами, акциями со сроками действия, медиатекой, контактами, реквизитами, цветами, шрифтом, индексацией и обращениями. Изменения сначала сохраняются в черновик. Кнопка «Опубликовать» обновляет сайт. При конфликте правок во вкладках панель предлагает обновить данные, а не перезаписывает чужой черновик.

Администратор управляет доступом, настройками и обращениями клиентов. Редактор управляет материалами и публикацией, но не учётными записями и персональными обращениями. История хранит 40 последних снимков. Восстановление создаёт черновик. JSON-копия содержит материалы и ссылки на файлы; пароли и обращения в неё не включаются. Оригиналы медиа следует резервировать вместе с каталогом сайта на хостинге.

## Структура

- `src/` — исходные HTML-страницы, стили, публичные скрипты и изображения.
- `server/admin/` — интерфейс, API, авторизация, публикация и приём обращений.
- `server/admin/catalog.seed.json` — первоначальные общедоступные примеры каталога, группы и бренды.
- `scripts/build.mjs` — производство серверной сборки или статической демонстрации.
- `scripts/check.mjs` — локальные ресурсы и правила индексации.
- `tests/cms_integration.py` — интеграционные HTTP-тесты в изолированной временной копии.

## Сборка и проверка

Нужен Node.js 20+. Сборка не требует npm-зависимостей.

```sh
npm run build:production
npm run check:production
python3 tests/cms_integration.py
```

Тесты требуют PHP 8.1+ в PATH и Python 3. Они запускают временный PHP-сервер на loopback, используют случайные тестовые учётные данные и удаляют временное окружение. Рабочий сайт не затрагивается.

В `dist/` попадают статические страницы и `admin/`. Для панели на сервере нужны PHP 8.1+, DOM, Mbstring, Fileinfo, сессии и права на запись в каталог сайта и `assets/`. Внешние CMS, база MySQL и Composer не требуются.

## Первоначальная настройка и данные

Стандартного логина или пароля нет. При установке отдельно подготавливается временный `admin/install-key.php`: он содержит только SHA-256 одноразового ключа и срок действия. Файл не входит в Git. Сам ключ передаётся владельцу во фрагменте URL первоначальной настройки, не попадает в HTTP-логи и удаляется из адресной строки приложением. Первый пароль владелец задаёт самостоятельно. После создания аккаунта повторная регистрация через первоначальную настройку запрещена, а временный файл удаляется.

На Rokmere закрытые данные находятся в `/home/u10019/www/.specparts49-cms/`, за пределами публичного каталога `/home/u10019/www/specparts49.ru/`. Это учётные записи с хешами паролей, сессии, черновики, журнал, история и обращения. Каталог создаётся с правами 0700, файлы — 0600. Не переносите эти данные в публичную папку или Git. Родительский каталог сайта должен разрешать создание закрытого хранилища. Для другого расположения web-root измените серверную конфигурацию пути в `lib.php` до установки.

Пароли хешируются средствами PHP. Включены HttpOnly/SameSite-сессии, смена идентификатора при входе, CSRF-проверка, ограничение попыток входа, разграничение прав, проверка загрузок, фильтрация HTML и журналирование. Загрузка PHP/HTML/JS как медиа запрещена. SVG с активным содержимым отклоняются.

## Обновление работающего сайта

После установки изменённое содержание хранится в закрытом каталоге хостинга. Оно не синхронизируется автоматически с GitHub: в Git не должны попадать клиентские обращения и учётные записи.

Перед обновлением кода сохраните копию содержимого из панели и резервную копию файлов хостинга. Обновляйте изменённые файлы `admin/` и публичных скриптов/стилей. Не заменяйте уже отредактированные на сайте HTML-страницы первоначальными шаблонами из `src/`. После обновления кода выполните публикацию из панели — страницы будут собраны из актуальных материалов, а версии ресурсов обновятся по содержимому файлов. Закрытый каталог, загрузки и временный установочный ключ при обновлении не перезаписываются.

## Обращения и почта

Приём обращений и почтовые уведомления изначально выключены по просьбе заказчика. Компания может заполнить контакты и сведения об обработке данных, затем включить приём в настройках. Обращения сохраняются в закрытой панели. Уведомления отправляются через почтовые средства хостинга; фактическую доставку необходимо проверить после настройки адреса получателя. SMTP-пароли в публичном JavaScript не используются.

## Статическая демонстрация

```sh
npm run build:demo
npm run check:demo
```

`.demo/` содержит только `src/`, без PHP, панели, серверных аккаунтов и хранения обращений. На всех демонстрационных страницах стоят `noindex, nofollow, noarchive, nosnippet`, а robots.txt содержит `Disallow: /`. Исходники движка остаются в `main`. Боевые страницы имеют открытую индексацию; панель всегда закрыта от неё.

## Материалы компании

Специализация: горнодобывающая и дорожно-строительная спецтехника, Caterpillar и Komatsu. С грузовой колёсной и легковой техникой предприятие не работает. Слоган: «С нами ваша техника всегда в строю».

Логотип компании и материалы Euroricambi/MCP предоставлены заказчиком. Источники остальных логотипов находятся в `src/assets/brands/sources.json`. Подтверждены 24 графических логотипа; HP и DZL представлены текстом. SF сопоставлен с SF-Filter. Перечень брендов не утверждает наличие каждого артикула или дилерский статус по всем производителям. Сертификат Euroricambi 2025, выданный другой компании, как сертификат Спецпартс49 не публикуется.
